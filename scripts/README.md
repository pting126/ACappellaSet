# Scripts

`prepare_mss.py` verifies and applies the pinned training patch to a clean,
dedicated MSS checkout. See [training](../docs/training.md).

The main commands live at the repository root: `inference.py`, `train.py`,
`prepare_specialists.py`, `evaluate.py`, and `download.py`.

`check_release.py` checks configuration/source/manifest hashes, frozen score
artifacts and local documentation links. `prepare_data.py`, `benchmark.py`, and
`reproduce.py` provide exact historical preparation, frozen-checkpoint testing,
and archive-derived tables; see [reproduction](../docs/reproduction.md).
